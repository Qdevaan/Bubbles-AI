# Screenshots

Drop product screenshots here. The README and the landing page (`docs/index.html`)
reference these exact filenames — add them and they appear automatically.

| Filename | Where it's used | Suggested content |
|----------|-----------------|-------------------|
| `hero.png`       | Landing page hero mockup (`docs/index.html`) | The most striking screen — Home or an active Wingman session. Recommended ~1200×800 or a phone frame. |
| `home.png`       | README screenshots row | Home / dashboard screen. |
| `wingman.png`    | README screenshots row | Live Wingman advice during a session. |
| `consultant.png` | README screenshots row | Consultant Q&A conversation. |
| `graph.png`      | README screenshots row | Knowledge graph explorer. |

## Tips

- **Format:** PNG preferred (crisp UI). WebP also fine if you update references.
- **Aspect:** keep the four README shots a similar aspect ratio so the row aligns (they render at 24% width each).
- **Hero:** `hero.png` shows inside a browser/phone mockup frame on the site; if it's
  missing, the site shows a graceful placeholder instead of a broken image.
- **Social preview:** for the GitHub repo social card, export a 1280×640 PNG and upload it
  under **Settings → General → Social preview** (this does not need to live in the repo).
